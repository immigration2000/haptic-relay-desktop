# Windows 설치 및 삭제 안내서

이 문서는 일반 사용자가 Haptic Relay Windows 앱을 내려받아 설치하고, 하드웨어 없이 스트리머와 시청자 간 모션 전송을 확인한 뒤 업데이트하거나 삭제하는 절차를 설명합니다.

## 1. 준비 사항

- Windows 10 또는 Windows 11 64비트 PC
- 스트리머와 시청자가 함께 사용할 릴레이 서버 URL
- 인터넷 연결
- OSR/T-Code 하드웨어는 기본 연동 확인에 필요하지 않음

앱과 릴레이 서버는 별도 프로그램입니다. Windows 설치 파일에는 릴레이 서버가 포함되어 있지 않습니다. 외부 시청자와 테스트할 때는 양쪽 앱에 동일한 공개 `https://` 서버 URL을 입력해야 합니다.

`http://localhost:4174`는 같은 PC에서 개발용 서버를 직접 실행할 때만 사용할 수 있습니다. 다른 PC나 휴대폰에서는 스트리머 PC의 `localhost`에 접속할 수 없습니다.

## 2. 공식 설치 파일 다운로드

1. [Haptic Relay v0.1.1 Demo 1 릴리스](https://github.com/immigration2000/haptic-relay-desktop/releases/tag/v0.1.1-demo.1)를 엽니다.
2. `Assets`에서 `Haptic.Relay-0.1.1-demo.1-win-x64.exe`를 내려받습니다.
3. 필요한 경우 함께 제공되는 `.sha256` 파일도 내려받습니다.

GitHub가 자동으로 제공하는 `Source code` ZIP/TAR 파일은 개발 소스입니다. 일반 사용자는 Windows EXE를 받아야 합니다.

## 3. 파일 무결성 확인

PowerShell에서 다음 명령을 실행합니다. 다운로드 위치가 다르면 `$file` 경로를 수정합니다.

```powershell
$file = "$HOME\Downloads\Haptic.Relay-0.1.1-demo.1-win-x64.exe"
(Get-FileHash -Algorithm SHA256 -LiteralPath $file).Hash.ToLowerInvariant()
```

출력값이 아래 값과 정확히 같아야 합니다.

```text
c4953334b71e09388698d532c9837d67cec9cd06257e8000da251389532632b7
```

값이 다르면 파일을 실행하지 말고 삭제한 다음 공식 릴리스 페이지에서 다시 내려받습니다.

## 4. 설치

1. 내려받은 EXE를 실행합니다.
2. Windows SmartScreen 경고가 나오면 게시자가 `알 수 없는 게시자`인지 확인합니다. 현재 데모 설치 파일은 코드 서명 전입니다.
3. 공식 GitHub 릴리스에서 받았고 SHA-256이 일치할 때만 `추가 정보`와 `실행`을 차례로 선택합니다.
4. 설치 위치를 확인하고 설치를 완료합니다.
5. 바탕 화면 또는 시작 메뉴의 `Haptic Relay`를 실행합니다.

설치 방식은 현재 Windows 사용자 전용이며 기본 설치 위치는 다음과 같습니다.

```text
%LOCALAPPDATA%\Programs\Haptic Relay
```

백신이나 SmartScreen을 전체 비활성화할 필요는 없습니다. 공식 파일과 해시가 확인되지 않은 상태에서는 예외 등록도 하지 마십시오.

## 5. 스트리머 방 만들기

1. 앱 상단에서 `스트리머`를 선택합니다.
2. `서버 URL`에 준비된 릴레이 서버 주소를 입력합니다.
3. 방 이름을 3자 이상 입력합니다.
4. 필요한 경우 비밀번호를 입력합니다.
5. `자유입장` 또는 `신청입장`을 선택하고 `방 생성`을 누릅니다.
6. 방 관리 페이지에서 초대 코드를 복사해 시청자에게 전달합니다.

`신청입장`에서는 시청자의 요청을 스트리머가 `방 관리` 탭에서 승인해야 접속이 완료됩니다.

## 6. 시청자 입장

1. 시청자 PC에도 같은 EXE를 설치하고 앱을 실행합니다.
2. 앱 상단에서 `시청자`를 선택합니다.
3. 스트리머가 전달한 초대 코드를 붙여 넣고 `초대 코드 적용`을 누릅니다.
4. 표시 이름을 입력하고 `입장 요청`을 누릅니다.
5. 직접 입력하는 경우 스트리머와 동일한 서버 URL, 방 이름, 비밀번호를 사용합니다.
6. 입장 후 `수신 모니터` 페이지가 표시되는지 확인합니다.

## 7. 하드웨어 없이 전송 확인

1. 스트리머 앱의 `실시간 시연` 탭을 엽니다.
2. `시연 시작`을 누릅니다.
3. 위치와 강도 슬라이더를 움직입니다.
4. 시청자 앱의 `수신 모니터`에서 위치, 강도, 프레임 수신이 계속 갱신되는지 확인합니다.
5. 확인이 끝나면 스트리머 앱에서 `시연 중지`를 누릅니다.

시연 중에는 최신 위치와 강도가 초당 30회 전송됩니다. 시청자 화면에 `가상 수신 정상 / 하드웨어 미연결`이 표시되면 네트워크 수신 경로는 정상이며 실제 장비만 연결되지 않은 상태입니다.

## 8. 업데이트

1. 실행 중인 Haptic Relay 창을 모두 닫습니다.
2. 새 버전의 공식 설치 파일과 SHA-256을 확인합니다.
3. 기존 버전을 먼저 삭제하지 않고 새 설치 파일을 실행합니다.
4. 설치 후 앱을 열어 저장된 설정과 버전을 확인합니다.

설정은 앱 설치 폴더와 분리되어 있으므로 일반적인 덮어쓰기 업데이트에서는 유지됩니다.

## 9. 프로그램 삭제

### Windows 설정에서 삭제

1. `설정`을 엽니다.
2. `앱` > `설치된 앱`으로 이동합니다.
3. `Haptic Relay` 오른쪽의 메뉴를 누릅니다.
4. `제거`를 선택하고 안내에 따릅니다.

### 설치 폴더에서 삭제

Windows 설정에서 항목을 찾을 수 없으면 앱을 종료한 뒤 다음 파일을 실행합니다.

```text
%LOCALAPPDATA%\Programs\Haptic Relay\Uninstall Haptic Relay.exe
```

## 10. 설정까지 완전히 삭제

일반 제거는 사용자 설정과 Chromium 캐시를 남길 수 있습니다. 설정까지 초기화하려면 프로그램 제거 후 PowerShell에서 다음 폴더가 존재하는지 먼저 확인합니다.

```powershell
$dataPath = Join-Path $env:APPDATA 'haptic-relay-desktop'
Test-Path -LiteralPath $dataPath
```

더 이상 필요한 설정이 없을 때만 해당 폴더를 직접 삭제합니다.

```powershell
Remove-Item -LiteralPath $dataPath -Recurse
```

이 작업은 저장된 하드웨어 프로필, 보호 설정과 앱 캐시를 복구할 수 없게 삭제합니다.

## 11. 연결 문제 확인

- 스트리머와 시청자의 서버 URL이 완전히 같은지 확인합니다.
- 서버 URL 뒤의 불필요한 공백을 제거합니다.
- 공개 접속에서는 `https://` URL을 사용합니다.
- 브라우저에서 `서버주소/healthz`를 열어 `"ok": true`가 반환되는지 확인합니다.
- Cloudflare Quick Tunnel을 재시작했다면 주소가 바뀌었는지 확인합니다.
- 방 이름과 비밀번호의 대소문자 및 공백을 확인합니다.
- `신청입장` 방이면 스트리머가 입장 요청을 승인했는지 확인합니다.

개발용 로컬 서버 실행과 상세 진단은 [데스크톱 무하드웨어 시연 설명서](DESKTOP_DEMO_TEST_GUIDE.md)와 [문제 해결 기록](TROUBLESHOOTING.md)을 참고합니다.
